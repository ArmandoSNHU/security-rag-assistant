# NIST Cybersecurity Framework (CSF)

The NIST Cybersecurity Framework is a voluntary, risk-based structure for organizing a security program. It is technology-neutral and outcome-focused: it describes what a mature program should achieve rather than prescribing specific products.

## The core functions

The framework groups activities into functions. The long-standing five are Identify, Protect, Detect, Respond, and Recover; CSF 2.0 adds Govern as an overarching function that ties security to enterprise risk decisions.

- Govern — set the risk strategy, roles, and policies that steer the other functions.
- Identify — inventory assets, data, suppliers, and risks so the program knows what it protects.
- Protect — safeguards such as access control, awareness training, data security, and maintenance.
- Detect — monitoring and analysis that surface anomalies and security events.
- Respond — containment, analysis, and communication once an incident is confirmed.
- Recover — restoring services and capabilities, and folding lessons learned back into the program.

## How it is used

Organizations profile their current state against a target state, find the gaps, and prioritize investments. The framework pairs well with control catalogs like NIST SP 800-53 and with sector requirements, because its functions give leadership a plain-language way to talk about coverage and maturity.
